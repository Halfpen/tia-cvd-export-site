Tia CVD Export

A personal utility operated by Halfpen that exports cryptocurrency market CVD data from a local database to the operator’s Google Drive.

The utility uploads a market-data CSV and a matching status file for analysis. It checks the uploaded CSV before publishing its status. It does not place trades.

Google Drive access requires the account owner’s consent. The application is intended for personal use, not public registration.
